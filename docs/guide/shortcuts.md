# Raccourcis clavier

Sur macOS, ++ctrl++ est remplacé par ++cmd++.

| Raccourci | Action |
| --- | --- |
| ++ctrl+k++ | Rechercher |
| ++ctrl+n++ | Nouvel identifiant ou nouvelle tâche (selon la vue) |
| ++ctrl+g++ | Générateur |
| ++ctrl+l++ | Verrouiller |
| ++question++ | Liste des raccourcis |
| ++esc++ | Fermer la fenêtre ouverte |

Dans les fenêtres :

| Raccourci | Action |
| --- | --- |
| ++enter++ | Valider |
| ++tab++ / ++shift+tab++ | Passer d'un champ à l'autre |
| ++r++ | Régénérer (générateur) |
| ++arrow-up++ / ++arrow-down++ | Parcourir le menu **…** |
