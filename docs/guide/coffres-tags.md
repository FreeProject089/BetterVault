# Coffres et tags

## Coffres

Un coffre regroupe des identifiants et des tâches : par exemple *Personnel*, *Travail*, *Famille*. Tous les coffres d'un compte sont chiffrés avec le même mot de passe maître.

- **Créer** : bouton **+** à côté de *Coffres-forts*.
- **Changer de coffre** : cliquez sur son nom.
- **Renommer, changer le type, supprimer** : icône crayon au survol du coffre.

La suppression d'un coffre supprime tous ses identifiants et tâches. Le dernier coffre ne peut pas être supprimé.

## Tags

Les tags s'appliquent aux identifiants comme aux tâches.

### Ajouter des tags

Dans le formulaire d'un identifiant ou d'une tâche, champ **Tags** :

- tapez un nom puis ++enter++ ou ++comma++ ;
- les tags existants sont proposés pendant la saisie ;
- ++backspace++ dans un champ vide retire le dernier tag.

Les majuscules ne créent pas de doublon : `Travail` et `travail` désignent le même tag.

### Filtrer

La section **Tags** de la barre latérale indique le nombre d'éléments par tag dans le coffre actif. Cliquez sur un tag pour filtrer la liste ; cliquez à nouveau pour retirer le filtre.

### Gérer les tags

L'icône de réglage à côté de *Tags* ouvre la gestion :

- créer un tag
- renommer (le nouveau nom est appliqué à tous les éléments)
- choisir une couleur
- supprimer (le tag est retiré des éléments, les éléments sont conservés)
