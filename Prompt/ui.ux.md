Professional UI/UX dashboard mockup for a modern enterprise-grade Password, 2FA & Task Manager.
Visual Style: Swiss modernism, minimal, sleek, executive software aesthetic (inspired by Linear.app, Raycast, and 1Password 8).

Layout & Elements:

- Crisp 3-column layout:
  1. Left sidebar: Collapsible navigation with clean typographic workspace switchers, Vaults (Personal, Work), 2FA Vault, Advanced Tasks (Inbox, Today, Projects, Tags), Settings.
  2. Center column: Dense, highly legible list view of credentials and tasks with subtle status badges, search bar with keyboard shortcut hint (Cmd+K), and crisp vector monochrome service icons.
  3. Right panel: Detailed record view showing encrypted notes, masked password reveal with entropy meter, real-time 2FA countdown ring, passkey credential chip, and linked sub-tasks.
- Color Palette: Neutral deep slate/charcoal dark mode (#0D1117 / #161B22) with muted silver typography (#E6EDF3), crisp high-contrast border lines (#30363D), and subtle monochromatic accents. Zero saturated gradients, no cartoonish icons, no emojis.
- Iconography: Monoline SVG icons and official brand logos (Simple Icons style), elegant globe icon fallback for unknown domains.
- Typography: Ultra-clean sans-serif font (Inter / SF Pro Display) with tabular numbers for 2FA counters and perfect typographic hierarchy.
- Details: Authentic high-fidelity design system, 8px grid system, subtle micro-borders, clean glassmorphism overlays only on modals. Photorealistic screenshot quality, 8k resolution, crisp vector edges.
